# User guide (first prototype)
Start Python bridge and Godot as in `DEVELOPMENT_SETUP.md`. This is **SIMULATED** networking. Click Capture mouse, use WASD and mouse to walk/look. Escape releases pointer for buttons and terminal. Click orange loose cable, click PC B monitor, click orange switch Fa0/3 port; the cable turns green only when backend accepts connection. Ping from PC B to PC A via button; read synthetic trace (ARP request/reply then echo/reply) and assessment criteria. Switch CLI is not Cisco IOS: try the Mission B sequence in setup. Use `show interfaces`, `show mac address-table`, `show port-security`, `show running-config`, `show startup-config` to inspect; `end` exits configuration mode; `write memory` saves **in memory only**. The router cube is **VISUAL ONLY**. Assess uses bundled JSON rubric weights over current physical cable, successful modeled ping, sticky learned PC B MAC and saved configuration; scores and missing criteria appear in API response. Default bridge stores the active lab in SQLite: Save checkpoint captures a snapshot, Restore latest returns to it, and Reset clears current progress/config but retains checkpoints (no confirmation yet). Headless console and `--ephemeral` bridge do not persist. Disable a port (`shutdown`) or assign a different access VLAN to diagnose modeled drops; `no shutdown` restores. For headless play use `python -m tools.console`; `help` lists console actions. No packet capture or scan is performed.
